# Tooltip

A few words on hover or keyboard focus: what an icon button does, a name that was cut short. Wrap the element: `<Tooltip content="Notifications"><Button aria-label="Notifications" icon={<Bell />} /></Tooltip>`.

- Never the only place something important is said: touch screens don't hover.
- A few words, no sentences, no links or buttons inside; for those, a Popover.

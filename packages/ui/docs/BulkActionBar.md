# BulkActionBar

When rows are selected, what can be done to all of them, how many are selected, and a way out. "Select all 1,240" appears when the whole page is selected and there's more.

- `bar` replaces the table's toolbar; `floating` floats at the bottom of the screen, for long tables.
- Up to about five actions; put the destructive one last, as danger-soft.

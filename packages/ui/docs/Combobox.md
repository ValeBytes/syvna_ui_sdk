# Combobox

Pick one from a long list by typing: a customer, a country, a product. It filters as the person types; arrow keys and Enter pick. Put it in a Field.

- Under about 12 choices, Select is simpler. For several picks, the FilterBar's chips.
- Give options a `description` when names repeat ("Amara Okafor · Lagos").

It takes the same `variant` and `size` as Input, so it matches the fields around it.

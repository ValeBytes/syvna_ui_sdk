# Popover

Content that opens from a button and stays until a click away or Escape: filters, a short form, a picker. Pass `children` as a function to get `close` for a button that's done.

- For a list of actions, a Menu; for a hint, a Tooltip; for a task that needs full attention, a Dialog.
- Keep it small: if it scrolls, it should be a SidePanel.

# TagInput

Several values in one field: emails to invite, tags, recipients, keywords. Enter, comma or Tab adds what's typed; pasting a comma or line separated list adds them all; Backspace in an empty field removes the last.

- `suggestions` offer values as they type; `strict` allows only those.
- `validate` refuses a value with a message ("Not an email address").
- `visible` shows the first few and "+N" for the rest.

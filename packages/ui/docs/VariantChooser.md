# VariantChooser

When someone isn't happy with a part of their screen ("I don't like this field"), the agent offers other looks for it: small live previews right in the chat, the current one marked. "Compare all" opens them large in a dialog, each one live to try, with "Use this one".

- Build the options from the component's variants (the MCP tool get_variants lists them), each with a one-line `note` on when it suits.
- Three in the chat, the rest behind "+N more".
